# Приложение для онлайн курсов и уроков


## Описание
Бэкенд-часть SPA-веб приложения для размещения и подписки для образовательных курсов и отдельных уроков.
Пользователи могут выкладывать свои курсы и уроки, подписываться на них и оплачивать.

## Установка
1. Утановите и откройте программу Docker Desktop: 
```
https://www.docker.com/products/docker-desktop/
```
2. Запустите в терминале команду:
```
docker-compose up -d --build
```


## Документация и структура проекта:
Ознакомиться с моделями и эндпоинтами можно на страницах
[swagger](http://localhost:8000/swagger/) и [redoc](http://localhost:8000/redoc/)
